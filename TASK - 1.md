# Task 1 - Foundations & Environment Setup

# Objective -
 Build strong fundamentals in cybersecurity, networking, cryptography, and set up a professional cybersecurity lab.

# Topics Covered

# 1. Cybersecurity Basics
- CIA Triad: Confidentiality, Integrity, Availability
- Threat Types:
  - Phishing
  - Malware
  - DDoS
  - SQL Injection
  - Brute Force
  - Ransomware
- Attack Vectors:
  - Social Engineering
  - Wireless Attacks
  - Insider Threats

# 2. Lab Environment Setup
- VirtualBox / VMware
- Kali Linux as the attacker machine
- Metasploitable2 / DVWA as the target environment
- Private Host-Only Adapter network

# 3. Linux Fundamentals
- File system navigation: `cd`, `ls`, `pwd`
- File and directory permissions: `chmod`, `chown`
- Package management: `apt`, `dpkg`
- Networking commands: `ifconfig`, `ping`, `netstat`, `traceroute`

# 4. Networking Basics
- OSI Model and layer functions
- TCP/IP Protocol Suite
- DNS
- HTTP/HTTPS
- IP Addressing
- Subnetting
- NAT

# 5. Cryptography Basics
- Symmetric vs Asymmetric Encryption
- Hashing: MD5, SHA256
- Digital Certificates
- SSL/TLS
- Hands-on encryption and decryption using OpenSSL

# 6. Tool Info
- Wireshark — packet capture
- Nmap — network scanning
- Burp Suite — web proxy
- Netcat — network debugging
